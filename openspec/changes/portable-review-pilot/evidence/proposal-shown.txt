# Portable human review without a custom delivery framework

## Why
Let humans evaluate product intent, system changes and evidence while OpenSpec handles delivery, regardless of agent harness.

## What changes
- Who: Phoenix engineers and reviewers; product/domain experts consuming the result.
- What: prototype a replacement for four delivery skills; keep only Human review and Guided test as custom skills. No Phoenix feature implementation.
- Where: isolated prototype directory; ordinary files transferable to another checkout.
- When: explore → plan → implement/test → verify → human review → archive.
- Availability: local only; no product flag, shared rollout or deployment.

## How
- Change / Keep: custom OpenSpec schema with proposal/specs/tasks; stock OpenSpec workflows. Preserve the existing Phoenix setup during this trial.
- Verify: [AC1–AC3](specs/portable-change-review/spec.md); CLI integration tests, cross-tool generation and an offline review page. No account or database needed.
- Tradeoff / Recover: more files than a single living artifact, but no proprietary delivery layer. Stop using this directory to roll back; no migration needed.

## Capabilities
- New: portable-change-review (prototype contract, not a shipped Phoenix capability).
- Modified: none.

## Sources and decisions
OpenSpec 1.16.0 CLI/schema and generated skill contracts; existing six Phoenix skills. The requester chose OpenSpec delivery plus only two portable custom skills. This trial does not establish improved review speed or correctness on a real feature.
